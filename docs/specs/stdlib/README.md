# Jai standard library API specification

This specification records the public compatibility surface: module aliases, exported identifiers, complete procedure signatures, public aggregate fields and enum values, constants, conditional availability, and externally visible behavior and constraints.

The module names and exported aliases are compatibility requirements. Internal organization is intentionally unspecified: implementations may regroup or replace their modules and files, provided they re-export the compatible public names and preserve their documented behavior.

For declarations that are direct bindings to a C library, the specification may identify the library and version, input headers, target/ABI conditions, and binding-generator settings instead of repeating every vendor declaration. Jai-authored wrappers, compatibility aliases, and deviations from generated bindings still need their public signatures and behavior documented. The summarized input is sufficient to reproduce the compatible interface.

Procedure bodies and implementation algorithms are omitted. Behavior notes describe observable results, edge cases, ownership, errors, and platform constraints; guarantees that are not specified are called out as such. Native bindings preserve their declared ABI surface, while behavior supplied by an external library remains subject to that library's contract.

The links below are navigation for this specification only and do not prescribe the implementation's module or file layout.
