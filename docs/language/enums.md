# Enums

## What it is

`enum` and `enum_flags` declarations, their backing integer types, loose enums and the reflection data they expose. Types are `EnumInfo` in `crates/jaic/src/types.rs`; declaration is `new_enum_type` / `enum_items` in `crates/jaic/src/sema/structs.rs`.

## How it works

Members count up from zero; `NAME :: value;` sets an explicit value and numbering continues after it. The default backing type is 8 bytes wide (`size_of(Color) == 8`); an explicit base such as `enum u8` sets it.

```jai
Color :: enum { RED; GREEN :: 5; BLUE; }    // 0, 5, 6
Small :: enum u8 { A; B; C; }
Flags :: enum_flags u32 { READ; WRITE; EXEC; }
print("% % %\n", Color.GREEN, cast(int) Color.GREEN, Color.BLUE);   // GREEN 5 BLUE
print("% % %\n", size_of(Small), size_of(Color), size_of(Flags));   // 1 8 4
print("%\n", Flags.READ | Flags.EXEC);                              // READ | EXEC
```

Printing an enum value with no matching name shows the number (`cast(Color) 99` prints `99`). `enum_flags` members are powers of two (`READ`=1, `WRITE`=2, `EXEC`=4) and combine with `|` and `&`; `fl & .WRITE` is usable in `if`.

`Color.loose` is a loose enum (`Types::loose_enum`): it converts implicitly to and from integers (`l: Color.loose = 1; i: int = l;`).

`type_info(Color)` yields `names` and `values` arrays and `enum_type_flags` (`.FLAGS` is set for `enum_flags`). `enum_highest_value(Color)` is available. Members can also be generated by `#insert` inside the enum body (`tests/stdlib/enum-insert-members.jai`).

- An inferred member on the left of a comparison (`.FIRST == x`) takes the right operand's type: `check_binary` checks the right side first. A polymorphic struct's value parameter of enum type types its `.MEMBER` argument and default (`Ticket(.SECOND)`, `struct(_order: Stuff = .FIRST)`) through `poly_struct_param_type`.

## How to change it

Member evaluation is in `enum_items`; `#insert`ed members go through `eval_insert_enum_items`. Reflection data is built in `sema/typeinfo.rs::build_type_info`. `Color.names` is not a member; use `type_info`. Tests: `tests/stdlib/baked-enum-default.jai`, `compiler-enum-external-type.jai`.

## Configuration

None.

## Dependencies

`types.rs`, `sema/consteval.rs` for member value expressions, `sema/typeinfo.rs` for reflection.
