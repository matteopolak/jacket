# Regex engine benchmark

- Machine: Apple M5 (10 cores, 16 GiB), macOS 27.0, arm64
- Date: 2026-10-12, repository commit 87476c74
- Corpus: 16,777,320 bytes, seed 1, sha256 `0073664d695d080a` (generated by `benchmarks/regex/corpus.py`; 7/8 English-like ASCII with dates, e-mails and names, 1/8 Greek, Cyrillic, CJK and accented Latin)
- Versions: jaic 0.12.0, regex 1.13.1, regex-automata 0.4.18, RE2 2025-11-05_2, PCRE2 10.47, CTRE v3.9.0, Hyperscan 5.4.13
- Engines run one after another, one process each; best of 7 timed runs after the file is in memory. Regenerate with `python3 tools/regex_bench.py`.

## Notes

- **Jai `Regex.Static`**: Patterns compile while the program compiles (`Regex.Static`); counts use `find_all`, captures use typed `captures_all`.
- **Jai `Regex.compile`**: `Regex.compile` at run time; counts use `find_all`, captures use `captures_all` and `group`.
- **Rust `regex`**: `find_iter` / `captures_iter` (the reference for correctness).
- **Rust dense DFA**: regex-automata dense DFA built by build.rs and deserialized zero-copy; unanchored forward search, match ends only. No Unicode `\b`, no capture groups.
- **RE2**: RE2's `\w` and `\b` are ASCII-only (no Unicode word classes), so `\b\w+\b` splits words at accented letters.
- **PCRE2 JIT**: `PCRE2_UTF | PCRE2_UCP`, `pcre2_jit_match`: Unicode `\w`, `\b` and `\p{..}`.
- **CTRE**: Header-only, compiled by the C++ compiler; UTF-8 input with `ctre-unicode.hpp`. CTRE's `\w` and `\b` are ASCII-only. Compile time is the C++ build.
- **Hyperscan**: Block mode, UTF-8 + UCP, start-of-match reporting with non-overlapping filtering, since Hyperscan reports every match end. When UCP fails (a pattern too large, `\b`), ASCII classes are used and noted.
- **Not included**: Zig has no regular-expression engine in its standard library and is not installed here, so it is left out. `std::regex` is left out as well: libc++'s ECMAScript backtracking matcher recurses per character (stack overflow on a 16 MB subject), has no `\p{Greek}` and no Unicode `\w` on `char`, and is orders of magnitude slower than every engine above.
