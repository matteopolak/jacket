# Golden cases for jacket.toml path globs, run by jailint (Rust) and jaifmt (Jai).
# Format: pattern<TAB>path<TAB>match|nomatch. Paths are relative with `/` separators.
# `*` and `?` stay inside one path component, `**` crosses components, and a pattern
# matching a directory also matches everything inside it. A trailing `/` on the pattern is
# ignored, and an empty pattern matches nothing.
