# Files

The File and File_Utilities modules: walking this workspace, reading this guide, and writing and
deleting a file. In the browser, reads see the workspace and the standard library, and writes go to
an in-memory disk that lasts for one run.

## Map

- [main.jai](main.jai): Calls the section.
- [files.jai](files.jai): The walk, the read, and the write, read back and delete.
- [sandbox_files.jai](sandbox_files.jai): The browser's version of the directory walk.

## Things to try

- Add a heading to this file and run again: the program prints every heading it finds.
