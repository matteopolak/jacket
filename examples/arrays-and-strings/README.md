# Arrays and strings

Fixed arrays, views and `[..]` arrays, `for` loops and `remove`, then strings, `print` formatting,
String_Builder and here-strings.

## Map

- [main.jai](main.jai): Runs both sections.
- [arrays.jai](arrays.jai): Fixed arrays, array views, resizable arrays, `for` with `it` and `it_index`, `remove`.
- [strings.jai](strings.jai): Strings as byte views, formatting with `%`, splitting and joining, building strings.

## Things to try

- In arrays.jai, change the sieve limit and see how many primes there are.
- In strings.jai, print a value of your own type: `print` formats anything.
