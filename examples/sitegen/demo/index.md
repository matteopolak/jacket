# Welcome

This site was built by **sitegen**, a static site generator written in Jai. Read the
[introduction](guide/intro.md) or the [Markdown reference](guide/markdown.md#lists).

![The banner](img/banner.png)

The banner above is too big to inline, so it is published as a file named after its content. The
logo in the header is small, so it is written into the page.

## What you get

- Pages in `.md` files, with the folder layout kept.
- A template with `{{ placeholders }}`.
- Assets named by a hash of their bytes, safe to cache forever.
