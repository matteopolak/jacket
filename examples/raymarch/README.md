# Ray marching in text

A ray marcher that draws a 3D scene with characters: each cell shoots a ray into a scene described
by a signed distance function.

## Map

- [main.jai](main.jai): Calls the section.
- [raymarch.jai](raymarch.jai): The scene, the marcher and the shading.

## Things to try

- Move `CAMERA` or `LIGHT_DIRECTION`, or add a third sphere to `scene`.
